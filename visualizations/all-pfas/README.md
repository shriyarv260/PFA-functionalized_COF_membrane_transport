# Seven PFAS molecules

In VMD Main choose **File → Load Visualization State**, then open `view_all_pfas.vmd`. It embeds the coordinates and works from any download folder. Existing molecules are hidden, not deleted.

The scene compares PFBA, PFHxA, PFOA, PFNA, PFBS, PFHxS and PFOS. These are static PubChem computed 3D conformers of neutral parent acids, arranged for comparison; they are not aqueous anions or a molecular dynamics trajectory.

Individual PDB files, original PubChem JSON records and `provenance.json` preserve the source data. PDB connectivity does not preserve bond orders; use the JSON for those.
