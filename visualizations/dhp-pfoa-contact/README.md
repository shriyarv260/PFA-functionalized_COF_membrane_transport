# Illustrative DHP-fragment / PFOA contact

Open VMD Main → File → Load Visualization State and select view_contact.vmd. The state embeds the accompanying PDB coordinates and works from any download folder; it briefly writes and removes its own temporary coordinate file.

The gray structure is a capped local model of the paper’s 1,4-DHP linkage (Scheme, PDF p. 5). The COF continuation points are hydrogen capped. It is not a reconstructed periodic COF. The colored molecule is neutral PFOA from PubChem. The yellow dashed contact connects the acid hydrogen to an ester carbonyl oxygen, at a deliberately chosen 1.90 Å separation.

This is a plausible geometry illustration, not evidence of a stable hydrogen bond or of adsorption. The paper discusses aqueous carboxylate/surface interactions; this neutral-acid example does not reproduce that mechanism. Only the isolated DHP fragment was MMFF optimized. The pair has not been optimized, solvated, docked, or simulated.

See model_notes.json for the exact model, atom IDs, source, checks and limitations.
